# Workshop feedback · 2 minutes

[Español](es/workshop-feedback.md) · [README](README.md)

Copy this into your usual survey or give it out on paper. No name or account
needed. Return privately to the facilitator; do not post learner responses in
public issues. Do not include personal, patient, or workplace data.

Facilitator fills in: date ___ · workshop commit/tag ___ · runtime ___

1. Which can you explain now? Check any: axis meaning / broadcasting / contraction / rank budget / none yet.
2. Where did you get stuck? Notebook and heading: ___
3. What changed your mind? Name one prediction and the evidence: ___
4. What should we change? Shorten ___ / add an example of ___ / allow more time for ___

Facilitator note: record actual section times and anonymous counts of common
errors. Open one concrete issue for the next run. Keep raw responses private.
