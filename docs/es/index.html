¿Para quién es este taller?

Ingenieros de software que dan el salto a la IA

  • Deja de adivinar las formas de los arrays: lee código de PyTorch y JAX con total confianza.
  • Conecta una arquitectura limpia en Python con las matemáticas de alta dimensionalidad del ML.
  • Convierte tu experiencia en ingeniería en soltura práctica con el aprendizaje profundo.

Analistas de datos y científicos de datos tradicionales

  • Sal de los DataFrames 2D y domina los tensores 3D/4D que impulsan el aprendizaje profundo.
  • Ve más allá de Scikit-Learn para procesar imágenes, texto y secuencias complejas.
  • Amplía tus habilidades de análisis tabular hasta dominar las redes neuronales.

Practicantes autodidactas de ML

  • No vuelvas a quedarte atascado con un RuntimeError: size mismatch.
  • Explora el funcionamiento interno de las API de alto nivel para depurar rápidamente operaciones tensoriales que fallan.
  • Deja de tratar los modelos como cajas negras: entiende qué ocurre en cada capa.

Graduados STEM (Informática, Física, Matemáticas)

  • Lleva la teoría del álgebra lineal a código práctico en Python, listo para producción.
  • Aplica descomposiciones matriciales directamente a la compresión de datos y las redes neuronales.
  • Conecta los conceptos abstractos de clase con arquitecturas reales de aprendizaje automático.
